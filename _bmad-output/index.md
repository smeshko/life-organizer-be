## Project Overview

| Attribute | Value |
|-----------|-------|
| **Project Name** | life-organizer-be |
| **Repository Type** | Monolith |
| **Primary Language** | Python 3.13 |
| **Architecture** | Async REST API with LLM Integration |
| **Framework** | FastAPI |
| **Database** | PostgreSQL 16 |

**Description:** Voice-first intelligent agent API that classifies natural language input and routes to appropriate handlers (budget, reminder, shopping, calendar). Uses Claude AI for NLP and supports multi-transaction parsing.

## Getting Started

### Quick Start

```bash
# Clone and enter project
git clone <repository-url>
cd life-organizer-be

# Install dependencies
make dev

# Configure environment
cp .env.example .env
# Edit .env and set CLAUDE_API_KEY

# Start server
make run
```

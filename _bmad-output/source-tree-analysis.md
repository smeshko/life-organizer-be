## Project Structure Overview

This is a Python FastAPI backend service with:
- Async REST API endpoints
- PostgreSQL database with Alembic migrations
- Claude AI integration for natural language classification
- Handler-based architecture for processing different input categories

## Integration Points

### External Services
- **Anthropic Claude API**: Classification and NLP via `services/claude_classifier.py`
- **PostgreSQL**: Async database via `asyncpg` driver

### Internal Flow
```
API Routes → Orchestrator → Claude Classifier → Handlers → Database
```

1. Request arrives at `api/routes/classifier.py`
2. `ClassifierOrchestrator` coordinates classification
3. `ClaudeClassifier` calls Claude API with category-specific prompt
4. Handler (e.g., `budget_entry.py`) processes classified input
5. Handler persists to database and returns response

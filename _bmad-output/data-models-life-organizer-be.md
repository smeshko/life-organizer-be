The Life Organizer Backend uses SQLAlchemy 2.0 with async support for database models and Pydantic v2 for API schemas.

## Database Schema

**Database:** PostgreSQL 16
**Schema Namespace:** `budget`

### BudgetTransaction Table

| Column | Type | Nullable | Description |
|--------|------|----------|-------------|
| `id` | INTEGER | NO | Primary key (auto-increment) |
| `amount` | NUMERIC(10,2) | NO | Original transaction amount |
| `currency` | VARCHAR(3) | NO | Currency code (default: EUR) |
| `amount_bgn` | NUMERIC(10,2) | NO | Amount in BGN (historical) |
| `amount_eur` | NUMERIC(10,2) | YES | Amount in EUR (new records) |
| `date` | DATE | NO | Transaction date |
| `transaction_type` | VARCHAR(20) | NO | Expenses/Income/Savings |
| `category` | VARCHAR(50) | NO | Category name |
| `details` | TEXT | YES | Merchant/description |
| `created_at` | TIMESTAMP WITH TZ | NO | Record creation time |
| `updated_at` | TIMESTAMP WITH TZ | NO | Last update time |

**Indexes:**
- `ix_budget_transactions_date` on `date`
- `ix_budget_transactions_type` on `transaction_type`

**Constraints:**
- `check_amount_positive`: amount > 0
- `check_amount_bgn_non_negative`: amount_bgn >= 0

**Source:** `src/life_organizer/db/models/budget.py`

## Executive Summary

Life Organizer Backend is a **voice-first intelligent agent** that captures everyday life events through natural language and automatically routes them to appropriate organizational systems. The backend service provides:

- **Natural Language Classification**: Uses Claude AI to understand user intent
- **Multi-Transaction Parsing**: Processes up to 15 transactions from a single input
- **Category-Based Routing**: Routes to handlers for budget, reminder, shopping, calendar, notes, quotes
- **iOS App Integration**: Returns app actions for native iOS functionality

### Example Use Case

**Input:** "yesterday I spent 50 at DM and 120 at Next, today 5 at bakery"

**Output:** 3 budget transactions created with dates, amounts, categories, and merchant details extracted automatically.

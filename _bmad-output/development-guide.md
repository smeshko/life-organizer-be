# Development Guide - life-organizer-be

> Generated by document-project workflow on 2026-01-31
> Project Type: Backend (Python/FastAPI)

## Prerequisites

- Python 3.13+
- [uv](https://github.com/astral-sh/uv) package manager
- Git
- Claude API key from [Anthropic Console](https://console.anthropic.com/settings/keys)

## Quick Start

```bash
# 1. Clone and enter project
git clone <repository-url>
cd life-organizer-be

# 2. Install dependencies
make dev

# 3. Configure environment
cp .env.example .env
# Edit .env with your CLAUDE_API_KEY

# 4. Start development server
make run
```

Access the API at:
- **Base URL**: http://localhost:8000
- **API Docs**: http://localhost:8000/api/v1/docs
- **ReDoc**: http://localhost:8000/api/v1/redoc

## Development Workflow

### Git Branching

- `main` - Production-ready code
- `staging` - Development integration
- Feature branches: `feature/`, `refactoring/`, `documentation/`, `hotfix/`

### Creating Features

```bash
# 1. Start from staging
git checkout staging
git pull

# 2. Create feature branch
git checkout -b feature/your-feature

# 3. Make changes and run quality checks
make format
make lint
make type-check
make test

# 4. Commit (pre-commit hooks run automatically)
git add .
git commit -m "feat(scope): description"

# 5. Push and create PR to staging
git push origin feature/your-feature
```

### Commit Message Format

Use conventional commits:
- `feat(scope): description` - New feature
- `fix(scope): description` - Bug fix
- `docs(scope): description` - Documentation
- `refactor(scope): description` - Refactoring
- `test(scope): description` - Tests
- `chore(scope): description` - Maintenance

## Pre-commit Hooks

Hooks run automatically on `git commit`:

- Trailing whitespace removal
- YAML/JSON/TOML syntax check
- Large file detection (max 1MB)
- Merge conflict detection
- Private key detection
- Ruff linting and formatting
- MyPy type checking
- OpenAPI spec validation

## Database Migrations

```bash
# Run migrations
alembic upgrade head

# Create new migration
alembic revision --autogenerate -m "description"

# Check current version
alembic current

# Rollback one migration
alembic downgrade -1
```

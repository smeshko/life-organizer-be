# API Contracts - life-organizer-be

> Generated by document-project workflow on 2026-01-31
> Project Type: Backend (Python/FastAPI)

## Overview

The Life Organizer Backend provides a REST API for processing voice/text input and routing to appropriate handlers. The API supports multi-transaction parsing (up to 15 transactions per request).

## Base URL

- Development: `http://localhost:8000`
- Production: `https://api.life-organizer.example.com` (placeholder)

## API Versioning

All endpoints are prefixed with `/api/v1/`

## Endpoints

### Health & Status

| Method | Path | Description |
|--------|------|-------------|
| GET | `/` | Root endpoint with API information |
| GET | `/health` | Health check |
| GET | `/api/v1/health` | Versioned health check |
| GET | `/api/v1/status` | API configuration and endpoints |

### Classification

| Method | Path | Description |
|--------|------|-------------|
| POST | `/api/v1/process` | Process user input (multi-transaction) |

**Request Body:**
```json
{
  "input": "string (required, 1-1000 chars)",
  "category": "budget|shopping|reminder|calendar|note|quote|unknown (optional)"
}
```

**Response:** `Array<ProcessingResponse>`
```json
[
  {
    "success": true,
    "action_type": "backend_handled|app_action_required",
    "message": "string",
    "app_action": null | LogBudgetEntryAction | CreateReminderAction
  }
]
```

### Budget

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/budget/export` | Export transactions as TSV |

**Query Parameters:**
- `start_date` (required): Date in YYYY-MM-DD format

**Response:** `text/tab-separated-values`

## Error Responses

| Status | Description |
|--------|-------------|
| 422 | Validation error (empty input, too many transactions) |
| 500 | Server error during processing |
| 501 | Category not yet supported |

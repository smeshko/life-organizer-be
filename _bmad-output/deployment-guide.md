## Docker Compose Quick Start

### Prerequisites
- Docker Desktop installed
- Claude API key from [Anthropic Console](https://console.anthropic.com/settings/keys)

### Setup

```bash
# 1. Configure environment
cp .env.example .env
# Edit .env and set CLAUDE_API_KEY

# 2. Start all services
docker-compose up --build

# Or run in background
docker-compose up -d --build
```

### Access Points
- **API**: http://localhost:8000
- **API Docs**: http://localhost:8000/api/v1/docs
- **Health Check**: http://localhost:8000/health

## Service Management

### Start/Stop Commands

```bash
# Start (foreground with logs)
docker-compose up

# Start (background)
docker-compose up -d

# Rebuild and start
docker-compose up --build

# Stop (keeps containers)
docker-compose stop

# Stop and remove containers
docker-compose down

# Stop and remove everything (including data)
docker-compose down -v
```

### Logs

```bash
# All services
docker-compose logs -f

# App only
docker-compose logs -f app

# Database only
docker-compose logs -f db

# Last 100 lines
docker-compose logs --tail=100 -f
```

## Database Management

### Connect to PostgreSQL

```bash
# Via docker-compose
docker-compose exec db psql -U life_organizer -d life_organizer

# Via psql from host
psql postgresql://life_organizer:life_organizer_dev_password@localhost:5432/life_organizer
```

### Migrations

Migrations run automatically on startup. Manual commands:

```bash
# Run migrations
docker-compose exec app alembic upgrade head

# Check status
docker-compose exec app alembic current

# Rollback one
docker-compose exec app alembic downgrade -1

# View history
docker-compose exec app alembic history
```

## Environment Configuration

### Required Variables
- `CLAUDE_API_KEY` - Anthropic Claude API key

### Optional Variables
- `DEBUG` - Enable debug mode (default: `true`)
- `LOG_LEVEL` - Logging level (default: `INFO`)
- `CORS_ORIGINS` - Allowed CORS origins
- `DATABASE_URL` - Database connection (auto-configured in Docker)

### Configuration Sources (priority order)
1. Environment variables
2. `.env` file
3. `docker-compose.yml` defaults

## Development with Docker

### Hot Reload

Modify `docker-compose.yml`:

```yaml
app:
  volumes:
    - ./src:/app/src:ro
  command: uvicorn life_organizer.main:app --host 0.0.0.0 --port 8000 --reload
```

### Run Tests

```bash
docker-compose exec app pytest
docker-compose exec app pytest --cov=life_organizer
```

### Shell Access

```bash
# Python shell
docker-compose exec app python

# Bash shell
docker-compose exec app bash
```

## Troubleshooting

### Database Connection Issues
```bash
docker-compose ps db
docker-compose logs db
docker-compose restart db
```

### App Won't Start
```bash
docker-compose logs app
docker-compose exec app alembic current
docker-compose down -v && docker-compose up --build
```

### Port Conflicts
Change port mapping in `docker-compose.yml`:
```yaml
ports:
  - "8001:8000"  # Use 8001 on host
```

### Reset Everything
```bash
docker-compose down -v
docker system prune -f
docker-compose up --build
```
